# Security Policy

## Supported Versions

Security fixes are considered for the latest public version of this project.

## Reporting a Vulnerability

Please do not publish sensitive vulnerability details in a public issue. Report the problem privately to the repository owner with:

- affected files or commands
- steps to reproduce
- expected impact
- suggested fix, if known

## Data Handling

MetricSense AI runs locally. It does not send input files anywhere unless you explicitly configure SMTP email delivery. Avoid committing real business spreadsheets, credentials, or generated reports.
